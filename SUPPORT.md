# Support

VaultGuard is an **unofficial, third-party** macOS client for Bitwarden / Vaultwarden servers, maintained on a best-effort basis.

## Getting help

- **Bugs:** open an issue using the **Bug report** template.
- **Feature ideas:** open an issue using the **Feature request** template.
- **Questions / discussion:** open an issue describing what you're trying to do.

Before filing, please search existing issues — yours may already be reported.

## What this project does *not* support

- **Setting up or operating your own Bitwarden / Vaultwarden server.** That's outside this client's scope — see the official [Bitwarden help](https://bitwarden.com/help/) or the [Vaultwarden wiki](https://github.com/dani-garcia/vaultwarden/wiki).
- **Account/billing issues with Bitwarden Inc.** VaultGuard is not affiliated with Bitwarden.

## Security

Do **not** report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md). Private contact: **a@krutilin.pro**, Telegram **@kruatech**.
